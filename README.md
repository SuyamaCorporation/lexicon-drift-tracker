# Lexicon Drift Tracker

**Category:** Writing & Linguistics Tools

Track how word meanings evolve across your personal writing corpus over time. Add words with contextual definitions, example sentences, semantic tags, and connotation labels (positive/neutral/negative/ambiguous). Visualizes semantic drift with timeline charts per word, highlights which words have shifted meaning, and provides an overview of stable vs. drifted vocabulary. All data persists in localStorage.
